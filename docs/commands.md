# 📋 Help Link (commands)

Answers help requests with a link to the full command reference ([commands.md](../commands.md) on GitHub).

---

## Setup

**No config needed.**

```
~/.sopel/scripts/commands.py
```

---

## Commands

| Command | Aliases | Description |
|---------|---------|-------------|
| `$help` | `$commands`, `$cmds` | Reply with the link to the command reference |

---

## Example

```
<User> $help
<Glitchy> User: Full command list: https://github.com/lord3nd3r/sopel-scripts/blob/main/commands.md
```
