# ᓚᘏᗢ Cat (cat)

Print a random unicode cat.

---

## Setup

**No config needed.**

```
~/.sopel/scripts/cat.py
```

**No data storage.**

---

## Commands

| Command | Description |
|---------|-------------|
| `$cat` | Say one of 15 unicode cats (never the same one twice in a row) |

---

## Example

```
<User> $cat
<Glitchy> ฅ^•ﻌ•^ฅ
```
