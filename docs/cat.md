# ᓚᘏᗢ Cat (cat)

> **Works with [ibot](https://github.com/lord3nd3r/ibot) (recommended) · Sopel-compatible.** Examples use the `$` prefix; ibot's default is `.`. To load these plugins, see the [Quick start](../README.md#-quick-start-with-ibot).

Print a random unicode cat.

---

## Setup

**No config needed.**

```
~/.sopel/scripts/cat.py
```

**No data storage.**

---

## Commands

| Command | Description |
|---------|-------------|
| `$cat` | Say one of 15 unicode cats (never the same one twice in a row) |

---

## Example

```
<User> $cat
<Glitchy> ฅ^•ﻌ•^ฅ
```
